# دکمه پشتیبانی شناور — WordPress Plugin

یک افزونه‌ی وردپرس که دکمه‌ای شناور در گوشه‌ی صفحه نمایش می‌دهد. با کلیک روی آن، گزینه‌های تماس از طریق شبکه‌های اجتماعی ظاهر می‌شوند.

---

## نصب

1. پوشه‌ی `support-widget` را در `wp-content/plugins/` قرار دهید.
2. از مسیر **افزونه‌ها** در پیشخوان وردپرس، افزونه را فعال کنید.
3. به **تنظیمات ← دکمه پشتیبانی** بروید و تنظیمات دلخواه را وارد کنید.

---

## ویژگی‌ها

- دکمه شناور با فونت **وزیرمتن** (Vazirmatn) — بدون نیاز به Google Fonts
- پشتیبانی از ۸ شبکه: تلگرام، واتس‌اپ، بله، روبیکا، ایتا، اینستاگرام، لینکدین، توییتر/X
- امکان افزودن شبکه سفارشی با نام و رنگ دلخواه
- نمایش اسم اپراتور در کنار نام شبکه
- **بارگذاری لوگوی اختصاصی** برای دکمه اصلی از کتابخانه رسانه وردپرس
- **انتخاب انیمیشن**: بدون انیمیشن / نبض / جهش / لرزش
- **انتخاب موقعیت**: پایین-راست یا پایین-چپ
- **ساعت کاری**: نمایش پیام آفلاین یا پنهان شدن خودکار خارج از ساعت کاری
- **پیام خوش‌آمد**: حباب متن با تأخیر قابل تنظیم
- **آمار کلیک**: شمارش کلیک‌ها به تفکیک کانال با تاریخ آخرین کلیک
- **مرتب‌سازی** کانال‌ها با Drag & Drop
- مخفی کردن دکمه در صفحات خاص (با وارد کردن ID)
- طراحی واکنش‌گرا (روی موبایل فقط آیکون)
- رعایت دسترس‌پذیری (ARIA)
- بدون وابستگی به jQuery در فرانت‌اند
