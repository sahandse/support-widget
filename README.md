# دکمه پشتیبانی شناور — WordPress Plugin

یک افزونه‌ی وردپرس که دکمه‌ای شناور در گوشه‌ی صفحه نمایش می‌دهد. با کلیک روی آن، گزینه‌های تماس از طریق **تلگرام، واتس‌اپ، بله، روبیکا و ایتا** ظاهر می‌شوند. هر شبکه‌ای که لینکش وارد نشده باشد، نمایش داده نمی‌شود.

---

## نصب

1. پوشه‌ی `support-widget` (یا هر نامی که به ریپو دادید) را در `wp-content/plugins/` قرار دهید.
2. از مسیر **افزونه‌ها** در پیشخوان وردپرس، افزونه را فعال کنید.
3. به **تنظیمات ← دکمه پشتیبانی** بروید و لینک‌های هر شبکه را وارد کنید.

---

## ویژگی‌ها

- دکمه‌ی شناور در گوشه‌ی پایین-راست صفحه
- پشتیبانی از ۵ شبکه: تلگرام، واتس‌اپ، بله، روبیکا، ایتا
- مخفی‌کردن خودکار شبکه‌های بدون لینک
- طراحی واکنش‌گرا (روی موبایل فقط آیکون، بدون برچسب متنی)
- رعایت دسترس‌پذیری (ARIA)
- بدون وابستگی به jQuery یا هیچ کتابخانه‌ی خارجی

---
