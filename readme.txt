دکمه شناور پشتیبانی برای سایت وردپرس با پشتیبانی از تلگرام، واتساپ، بله، روبیکا و ایتا.

== Description ==

افزونه «دکمه پشتیبانی» یک دکمه شناور به سایت شما اضافه می‌کند که با کلیک روی آن،
راه‌های ارتباطی با پشتیبانی نمایش داده می‌شود. پیام‌رسان‌های پشتیبانی‌شده:

* تلگرام (Telegram)
* واتساپ (WhatsApp)
* بله (Bale)
* روبیکا (Rubika)
* ایتا (Eitaa)

ویژگی‌ها:

* تنظیم نام کاربری یا شماره برای هر پیام‌رسان از پیشخوان
* فعال یا غیرفعال کردن هر کانال به‌صورت مستقل
* انتخاب موقعیت دکمه (راست یا چپ پایین صفحه)
* انتخاب رنگ اصلی دکمه
* طراحی واکنش‌گرا و سازگار با موبایل
* بدون وابستگی به سرویس بیرونی

== Installation ==

1. پوشه افزونه را در مسیر `/wp-content/plugins/` قرار دهید.
2. افزونه را از منوی «افزونه‌ها» در پیشخوان وردپرس فعال کنید.
3. به «تنظیمات → دکمه پشتیبانی» بروید و راه‌های ارتباطی را وارد کنید.
